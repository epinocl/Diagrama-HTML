Guardar y Versionar Planos AXON {{CODIGO}}
Elige si deseas sobreescribir los archivos locales con las correcciones manuales realizadas o guardarlos como una nueva versión con revisión actualizada.
1. Sobreescribir Archivo SVG de la Lámina Actualizar Hoja
Sobreescribe directamente el archivo vectorial dependencias/hojas/hoja_01.svg con las nuevas posiciones de los textos.
2. Guardar como Nueva Versión / Revisión Versionar
Actualiza automáticamente el casillero REV. y la fecha de hoy en el cajetín de esta lámina, y genera un nuevo archivo SVG versionado.
1. Sobreescribir Base de Datos del Proyecto Permanente
Actualiza y sobreescribe el archivo maestro dependencias/js/hojas_svg_inline.js con todas las láminas. Al reemplazarlo, las correcciones quedan aplicadas permanentemente para cualquier usuario que abra el visor.
2. Guardar Proyecto como Nuevo Archivo HTML Autónomo
Genera un nuevo archivo HTML versionado independiente (ej: diagrama_proyecto_RevA.html) con todas las láminas y estilos listos para archivar o enviar.
💡 En Chrome o Edge, el explorador permite seleccionar y reemplazar el archivo directamente.
🎨 Configurar Colores de Impresión (Paper Space / PDF)
Personaliza los tonos de cada conjunto de textos y elementos en el Modo Impresión. Los cambios se actualizan en vivo en todas las láminas y se conservan al imprimir en PDF.
